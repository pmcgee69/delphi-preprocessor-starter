# The Delphi version (planned)

The same engine and rules, in Delphi, on [TreeSitter4D](https://github.com/pmcgee69/TreeSitter4D):
its released objects or DLLs give Delphi the grammar with no C compiler.

It will share `..\tests\cases`: each rule's inputs and expected outputs, so a rule written in
both languages has to behave the same in both.
